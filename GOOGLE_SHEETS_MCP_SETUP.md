**Чтение данных:**
```

```

## 🔐 Безопасность

### ⚠️ ВАЖНО

**НИКОГДА не коммитьте credentials в Git!**

Проверьте что `.gitignore` содержит:
```gitignore
.credentials/
*.json
```

Проверка безопасности:
```bash
git status
# Не должно показывать .credentials/ или google-sheets-key.json
```

### Восстановление после утечки

Если случайно закоммитили ключ:
1. Немедленно удалите Service Account в Google Cloud Console
2. Создайте новый Service Account
3. Скачайте новый JSON ключ
4. Замените файл в `.credentials/google-sheets-key.json`
5. Перезапустите Claude Code

## 📊 Структура таблицы

Google Sheets MCP работает с вашей таблицей:

| Столбец | Название | Пример использования |
|---------|----------|---------------------|
| A | CHECKBOX | Фильтр: `где столбец A = TRUE` |
| B | ARTICLE | Поиск: `найди артикул 26175` |
| C | INSALES_ID | `покажи INSALES_ID для артикула X` |
| D | PRODUCT_NAME | Поиск: `товары содержащие "Veber"` |
| E | ORIGINAL_IMAGES | `товары без изображений InSales` |
| F | SUPPLIER_IMAGES | `товары с изображениями поставщиков` |
| K | PROCESSING_STATUS | Фильтр по статусу обработки |
| L | INSALES_STATUS | Фильтр по статусу отправки |

## ❌ Устранение неполадок

### Сервер не подключается
**Проверьте:**
1. VSCode перезапущен после изменения `.mcp.json`
2. Файл `.credentials/google-sheets-key.json` существует
3. JSON ключ валиден (откройте в текстовом редакторе)

**Команда проверки:**
```bash
cat /Users/evgenijermakov/Documents/Фото/.credentials/google-sheets-key.json | head -n 1
# Должно показать: { "type": "service_account", ...
```

### "Access denied" ошибка
**Причина:** Service Account не имеет доступа к таблице

**Решение:**
1. Откройте таблицу в Google Sheets
2. Нажмите "Поделиться"
3. Проверьте что `claude-code-sheets@gen-lang-client-0597231611.iam.gserviceaccount.com` в списке с правами "Редактор"

### "Invalid credentials" ошибка
**Причина:** JSON ключ поврежден или неправильный Project ID

**Решение:**
1. Скачайте новый JSON ключ из Google Cloud Console
2. Замените файл в `.credentials/google-sheets-key.json`
3. Перезапустите VSCode
