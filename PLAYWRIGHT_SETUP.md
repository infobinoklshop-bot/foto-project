## Зачем нужен для вашего проекта

### Замена UrlFetchApp для парсинга поставщиков

**Текущая проблема:**
В [05_supplier_parsing.gs.js](05_supplier_parsing.gs.js) используется `UrlFetchApp.fetch()`, который:
- ❌ Не выполняет JavaScript на странице
- ❌ Не видит контент, загружаемый динамически (AJAX, React)
- ❌ Не может взаимодействовать со страницей (клики, скролл)
- ❌ Часто блокируется как бот

**С Playwright:**
- ✅ Полноценный браузер - видит всё как пользователь
- ✅ Выполняет JavaScript - получает динамический контент
- ✅ Автоматизация: клики, ввод, навигация
- ✅ Обход защиты от ботов

## Ключевые преимущества

### 1. Accessibility Tree вместо скриншотов
- Playwright анализирует структуру DOM, не пиксели
- Быстрее и точнее
- Не нужны vision модели (GPT-4 Vision)

### 2. Надежность
- Автоматическое ожидание элементов
- Retry механизмы
- Обработка динамического контента

### 3. Универсальность
- Поддержка Chrome, Firefox, Safari (WebKit)
- Работает с SPA (React, Vue, Angular)
- Эмуляция мобильных устройств

## Опции запуска (можно добавить в конфигурацию)

```json

  }
```


## Сравнение: UrlFetchApp vs Playwright

| Функция | UrlFetchApp (сейчас) | Playwright (новое) |
|---------|---------------------|-------------------|
| Простой HTML | ✅ | ✅ |
| Динамический JS контент | ❌ | ✅ |
| Взаимодействие (клики) | ❌ | ✅ |
| Ожидание загрузки | ❌ | ✅ |
| Эмуляция браузера | ❌ | ✅ |
| Обход защиты от ботов | ❌ | ✅ |
| Простота использования | ✅ (встроено в Apps Script) | ⚠️ (требует внешний вызов) |
| Скорость | ⚡ Быстро | 🐌 Медленнее |
| Стоимость | 🆓 Бесплатно | 🆓 Бесплатно |

## Рекомендации

**Используйте UrlFetchApp когда:**
- Простой HTML без JavaScript
- Быстрый парсинг
- Статический контент

**Используйте Playwright когда:**
- Динамический контент (React, Vue, AJAX)
- Нужны действия (клики, скролл)
- Сайт блокирует боты
- Требуется авторизация
