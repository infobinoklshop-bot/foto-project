# MCP Серверы - Шпаргалка

## 🚀 Быстрый старт

### Когда что использовать

| Нужно | Напиши | MCP сервер |
|-------|--------|------------|
| Актуальная документация API | "use context7 - OpenAI API" | Context7 |
| Парсинг сайта | "Используй Playwright для..." | Playwright |
| Данные из Google Sheets | "Покажи таблицу..." | Google Sheets |
| Прочитать файл | Автоматически | Filesystem |
| Сохранить решение | "Сохрани в Memory Bank" | Memory Bank |

## 📝 Магические фразы (триггеры)

### Context7 автоматически активируется при:
- "InSales API", "OpenAI API", "Google Apps Script API"
- "актуальный метод", "документация", "пример кода"
- "use context7 - ..."

### Playwright автоматически активируется при:
- "парсинг", "сайт", "веб-страница"
- "Veber.ru", "Sturman.ru", "InSales магазин"
- "Используй Playwright для..."

### Memory Bank автоматически используется при:
- "сохрани решение", "запиши это"
- Сложные многоэтапные задачи
- Важные архитектурные решения

### Google Sheets автоматически активируется при:
- "покажи таблицу", "найди в таблице"
- "обнови статус", "сколько товаров"
- Упоминание "Фото товаров - Обработка изображений"

## ⚡ Готовые команды

### Парсинг
```
Используй Playwright для анализа https://veber.ru/product/26175/
Найди селекторы для изображений и характеристик
```

### API документация
```
use context7 - актуальные endpoints InSales API для загрузки изображений
```

### Отладка
```
Проверь актуальность методов OpenAI API в 07_description_ai.js
```

### Рефакторинг
```
Проанализируй 05_supplier_parsing.gs.js и предложи улучшения
с учетом современных best practices
```

### Работа с таблицами
```
Покажи последние 10 товаров из таблицы "Фото товаров - Обработка изображений"

Найди все товары со статусом "Ошибка"

Обнови статус товара 26175 на "Обработано"
```

## 🎯 Паттерны использования

### Паттерн 1: Новая функция
1. Context7 → изучи best practices
2. Filesystem → реализуй код
3. Memory Bank → сохрани решение

### Паттерн 2: Фикс бага
1. Filesystem → прочитай код
2. Context7 → проверь актуальность
3. Playwright → протестируй (если веб)
4. Memory Bank → запиши решение

### Паттерн 3: Парсинг сайта
1. Playwright → анализ структуры
2. Filesystem → обнови код
3. Memory Bank → сохрани селекторы

### Паттерн 4: Анализ данных
1. Google Sheets → получи данные
2. Filesystem → обнови код на основе найденного
3. Google Sheets → обнови статусы

## 🔑 Ключевые правила

1. **Будь конкретен:** Упоминай технологии (InSales, OpenAI, Veber.ru)
2. **Требуй сохранения:** "Сохрани это в Memory Bank"
3. **Проси актуальность:** "Проверь через Context7"
4. **Используй Playwright:** Для любого парсинга

## 💡 Примеры из жизни

**Задача:** Парсинг сломался после редизайна Veber.ru

**Плохо:**
```
"Парсинг не работает"
```

**Хорошо:**
```
"Veber.ru изменили структуру страницы.
Используй Playwright чтобы найти новые селекторы для товара 26175
и обнови функцию parseVeberImages в 05_supplier_parsing.gs.js"
```

**Что произойдет:**
✅ Playwright откроет страницу
✅ Найдет новые селекторы
✅ Filesystem обновит код
✅ Memory Bank сохранит изменения
