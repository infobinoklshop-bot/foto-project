# Руководство по редактированию параметров в диалоге "Управление параметрами"

## Обзор новых возможностей

В диалоговом окне **"Управление параметрами"** (вкладка **"📦 Товар"**) теперь доступно:

1. ✏️ **Редактирование сопоставленного параметра** - изменение параметра справочника для уже сопоставленных полей
2. ✏️ **Редактирование нормализованного значения** - корректировка значения параметра
3. 💾 **Сохранение новых значений в справочник** - добавление отредактированных значений в список допустимых

---

## Интерфейс вкладки "📦 Товар"

### Секция "✅ Сопоставленные параметры"

Каждый сопоставленный параметр теперь отображается в виде **редактируемой строки** с 6 столбцами:

| Столбец | Назначение | Редактируемость |
|---------|-----------|----------------|
| **Поле поставщика** | Исходное название поля от поставщика | Только чтение |
| **Исходное значение** | Оригинальное значение от поставщика (жёлтая рамка) | Только чтение |
| **→** | Стрелка указывает направление сопоставления | - |
| **Параметр справочника** | Название канонического параметра | **✏️ Редактируемое** с автодополнением |
| **Нормализованное значение** | Обработанное значение (зелёная рамка) | **✏️ Редактируемое** |
| **Действия** | Кнопки управления | 2 кнопки (появляются при изменениях) |

---

## Сценарии использования

### 1️⃣ Изменение параметра справочника

**Задача:** Вы хотите сопоставить поле поставщика с **другим** параметром справочника.

**Шаги:**

1. В секции **"✅ Сопоставленные параметры"** найдите нужную строку
2. Кликните в поле **"Параметр справочника"** (4-й столбец)
3. Начните вводить название параметра - появится **выпадающий список** с подсказками
4. Выберите нужный параметр из списка или введите полностью
5. Автоматически появится кнопка **"↩️ Сброс"** для отмены изменений

**Результат:**
- Строка помечена как изменённая
- Счётчик в подвале: "Изменено параметров: 1"

**Применение:**
- Нажмите **"🔄 Обновить товар"** - изменения применятся только к текущему товару
- Нажмите **"📖 Обновить справочник"** - добавит новое сопоставление в справочник + ре-нормализует ВСЕ товары

---

### 2️⃣ Редактирование нормализованного значения

**Задача:** Значение нормализовано неправильно, нужно его исправить.

**Шаги:**

1. Найдите строку с некорректным значением
2. Кликните в поле **"Нормализованное значение"** (5-й столбец)
3. Отредактируйте значение вручную (например, `"Б-8 7x40"` → `"8x40"`)
4. При изменении автоматически появятся 2 кнопки:
   - **"💾 Сохранить"** - добавить это значение в список допустимых
   - **"↩️ Сброс"** - вернуть исходное значение

**Результат:**
- Изменённое значение будет использовано при обновлении товара

---

### 3️⃣ Сохранение нового значения в справочник

**Задача:** Вы отредактировали нормализованное значение и хотите **добавить его в список допустимых** для этого параметра, чтобы в будущем оно распознавалось автоматически.

**Шаги:**

1. Отредактируйте нормализованное значение (как в сценарии 2)
2. Нажмите кнопку **"💾 Сохранить"** рядом с полем
3. Подтвердите действие во всплывающем окне:
   ```
   Добавить значение "8x40" в список допустимых значений параметра "Кратность увеличения, крат"?
   
   Это действие обновит справочник параметров.
   ```
4. Дождитесь уведомления об успехе

**Результат:**
- Новое значение добавлено в колонку **"Допустимые значения"** (column D) в листе **"Справочник параметров"**
- Значение отсортировано по алфавиту среди других допустимых значений
- При следующей нормализации это значение будет автоматически распознаваться как корректное

**Пример из жизни:**
```
До изменения в справочнике:
Параметр: "Модель"
Допустимые значения: "Б-7 8x30; Б-8 7x40; Б-10 15x70"

Вы редактируете значение: "Б-8 7x40" → "8x40"
Нажимаете "💾 Сохранить"

После изменения в справочнике:
Параметр: "Модель"
Допустимые значения: "8x40; Б-7 8x30; Б-8 7x40; Б-10 15x70"
```

---

### 4️⃣ Сброс изменений

**Задача:** Вы передумали и хотите вернуть исходные значения.

**Шаги:**

1. Нажмите кнопку **"↩️ Сброс"** рядом с изменённой строкой
2. Все поля вернутся к исходным значениям
3. Кнопки "Сохранить" и "Сброс" исчезнут

**Результат:**
- Изменения отменены
- Строка удалена из списка модификаций

## Автодополнение параметров

При редактировании поля **"Параметр справочника"** доступна функция автодополнения:

**Как работает:**
- Введите **минимум 2 символа** из названия параметра
- Система отфильтрует список всех параметров из справочника
- Показывается максимум **10 совпадений**
- Совпадающие символы подсвечены **жёлтым**
- Используйте мышь или клавиши ↑↓ для навигации

**Примеры запросов:**
- `"увел"` → найдёт "Кратность увеличения, крат"
- `"диам"` → найдёт "Диаметр объектива, мм"
- `"защ"` → найдёт "Защита от влаги и пыли"

**Преимущества:**
- Быстрый поиск среди 600+ параметров
- Предотвращение опечаток
- Автоматическая валидация (выбрать можно только существующий параметр)

## Часто задаваемые вопросы (FAQ)

### ❓ Что происходит при нажатии "🔄 Обновить товар"?

**Ответ:**
1. Система применяет все изменения **только к текущему товару**
2. Обновляется колонка **Q** (Нормализованные спецификации) в таблице
3. Справочник параметров **НЕ изменяется**
4. Другие товары **НЕ затрагиваются**

**Использовать когда:**
- Нужно быстро исправить один товар
- Не уверены, что изменение должно применяться глобально

---

### ❓ Что происходит при нажатии "📖 Обновить справочник"?

**Ответ:**
1. Все изменения добавляются в **"Справочник параметров"** как новые синонимы
2. Система **ре-нормализует ВСЕ товары** в таблице (может занять несколько минут)
3. Появится предупреждение перед выполнением:
   ```
   ⚠️ ВНИМАНИЕ!
   
   Это действие обновит справочник параметров и ре-нормализует ВСЕ товары в таблице.
   
   Изменений: 3
   
   Процесс может занять несколько минут.
   
   Продолжить?
   ```

**Использовать когда:**
- Хотите, чтобы изменение применялось ко всем будущим импортам
- Нашли системную ошибку в сопоставлении

---

### ❓ Что происходит при нажатии "💾 Сохранить" рядом с нормализованным значением?

**Ответ:**
1. Новое значение добавляется в колонку **D** (Допустимые значения) в листе **"Справочник параметров"**
2. Значения сортируются по алфавиту
3. Если значение уже существует, показывается уведомление без изменений
4. Справочник обновляется **немедленно**, без ре-нормализации всех товаров

**Важно:**
- Это действие **не пере-нормализует** другие товары автоматически
- Для применения к другим товарам используйте вкладку **"📋 Все ненормализованные значения"**

---

### ❓ Можно ли редактировать несколько параметров одновременно?

**Ответ:**
Да! Вы можете:
1. Отредактировать несколько строк подряд
2. Каждая изменённая строка добавится в счётчик изменений
3. При нажатии "🔄 Обновить товар" все изменения применятся одновременно

**Пример:**
```
Изменено параметров: 5
```

Это означает, что вы изменили 5 разных строк в таблице сопоставленных параметров.

---

### ❓ Можно ли отменить изменения после применения?

**Ответ:**
- **До применения:** Да, используйте кнопку **"↩️ Сброс"** рядом с каждой изменённой строкой
- **После применения через "🔄 Обновить товар":** Частично - откройте диалог снова, внесите обратные изменения
- **После применения через "📖 Обновить справочник":** Сложнее - потребуется вручную редактировать справочник и пере-нормализовать товары

**Рекомендация:**
Всегда используйте **"🔄 Обновить товар"** для тестирования перед глобальным обновлением справочника.

---

### ❓ Как проверить, что новое значение добавлено в справочник?

**Ответ:**

**Способ 1: Через уведомления**
После нажатия "💾 Сохранить" появится уведомление:
```
✅ Справочник обновлен

Значение "8x40" добавлено в список допустимых значений параметра "Модель"
```

**Способ 2: Проверка в листе**
1. Откройте лист **"Справочник параметров"**
2. Найдите нужный параметр в колонке **B**
3. Проверьте колонку **D** (Допустимые значения)
4. Новое значение должно быть в списке через точку с запятой

**Способ 3: Проверка при следующей нормализации**
1. Импортируйте товар с таким же исходным значением
2. Если нормализация прошла успешно - значение в справочнике

## Лучшие практики

### ✅ Рекомендуется

1. **Всегда проверяйте автодополнение** - если параметр есть в списке, используйте его точное название
2. **Используйте "Сохранить" для enum-значений** - если параметр типа `enum`, добавляйте новые варианты через кнопку "💾"
3. **Тестируйте на одном товаре** - сначала "🔄 Обновить товар", проверьте результат, затем "📖 Обновить справочник"
4. **Сбрасывайте ошибки сразу** - если ошиблись, нажмите "↩️ Сброс" до применения изменений
5. **Проверяйте тип поля** - перед добавлением значения убедитесь, что параметр типа `enum` (иначе добавление бессмысленно)

### ❌ Не рекомендуется

1. **Не изобретайте новые параметры** - если название параметра нет в автодополнении, скорее всего оно неправильное
2. **Не добавляйте очевидно неправильные значения** - проверяйте логику перед сохранением (например, не сохраняйте "да" как допустимое значение для "Диаметр объектива, мм")
3. **Не используйте глобальное обновление для экспериментов** - кнопка "📖 Обновить справочник" может пере-нормализовать сотни товаров
4. **Не редактируйте справочник напрямую во время работы диалога** - используйте предоставленный интерфейс

## Примеры из практики

### Пример 1: Исправление модели бинокля

**Проблема:**
Поставщик присылает модель как `"Б-8 7x40"`, нормализатор не распознаёт формат, оставляет как есть. Нужно `"8x40"`.

**Решение:**
1. Открыть диалог для товара
2. Найти параметр `"Модель"` в секции "✅ Сопоставленные"
3. В поле "Нормализованное значение" изменить `"Б-8 7x40"` → `"8x40"`
4. Нажать **"💾 Сохранить"**
5. Подтвердить добавление в справочник
6. Нажать **"🔄 Обновить товар"**

**Результат:**
- Текущий товар обновлён со значением `"8x40"`
- В справочнике добавлено допустимое значение `"8x40"` для параметра `"Модель"`
- При следующем импорте товара с `"8x40"` нормализация пройдёт автоматически

---

### Пример 2: Переназначение параметра

**Проблема:**
Поле поставщика `"Увеличение"` сопоставлено с параметром `"Диаметр объектива, мм"` (ошибка в справочнике). Нужно исправить на `"Кратность увеличения, крат"`.

**Решение:**
1. Открыть диалог для товара
2. Найти строку с ошибочным сопоставлением в "✅ Сопоставленные"
3. Кликнуть в поле "Параметр справочника"
4. Начать вводить `"Кратность"`
5. Выбрать из автодополнения `"Кратность увеличения, крат"`
6. Нажать **"📖 Обновить справочник"** (чтобы исправить для всех товаров)
7. Подтвердить глобальное обновление

**Результат:**
- В справочнике обновлён синоним: `"Увеличение"` теперь ведёт на `"Кратность увеличения, крат"`
- Все товары с полем `"Увеличение"` пере-нормализованы
- Будущие импорты используют правильное сопоставление
