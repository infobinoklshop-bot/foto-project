# MCP Серверы - Best Practices для Google Apps Script проекта

## 🎯 Как формулировать запросы для максимальной эффективности

### ✅ Хорошие запросы (автоматически используют MCP)

**Context7 активируется автоматически:**
```
❌ "Как загрузить изображение в InSales?"
✅ "Покажи актуальный метод загрузки изображений через InSales API"

❌ "Помоги с OpenAI API"
✅ "Как правильно использовать OpenAI Assistants API для обработки описаний?"

❌ "Что-то не работает с UrlFetchApp"
✅ "Актуальные параметры Google Apps Script UrlFetchApp для POST запросов"
```

**Playwright активируется автоматически:**
```
❌ "Нужно получить данные с сайта"
✅ "Проанализируй структуру страницы Veber.ru через Playwright"

❌ "Проверь парсинг"
✅ "Используй Playwright чтобы открыть Sturman.ru и найти селекторы для изображений"
```

**Memory Bank используется проактивно:**
```
✅ "Найди решение для rate limiting InSales API и сохрани для будущего"
✅ "Исследуй как работает нормализация спецификаций и запиши архитектуру"
✅ "Проанализируй проблему с дубликатами товаров и сохрани выводы"
```

## 🔄 Практические сценарии использования

### Сценарий 1: Отладка парсинга поставщика

**Ваш запрос:**
```
Парсинг Veber.ru возвращает пустые изображения для артикула 26175
```

**Что произойдет автоматически:**
1. ✅ Playwright откроет https://veber.ru и проанализирует структуру
2. ✅ Context7 проверит актуальность методов UrlFetchApp
3. ✅ Filesystem прочитает 05_supplier_parsing.gs.js
4. ✅ Memory Bank сохранит найденное решение в "veber-parsing-fixes.md"

### Сценарий 2: Обновление API интеграции

**Ваш запрос:**
```
Нужно обновить код загрузки изображений в InSales, используется старый метод
```

**Что произойдет автоматически:**
1. ✅ Context7 получит актуальную документацию InSales API
2. ✅ Filesystem прочитает 03_insales_api.js
3. ✅ Предложит обновленный код с новыми endpoints
4. ✅ Memory Bank запишет breaking changes для будущего

### Сценарий 3: Добавление нового поставщика

**Ваш запрос:**
```
Нужно добавить парсинг товаров с сайта newshop.ru
```

**Что произойдет автоматически:**
1. ✅ Playwright откроет newshop.ru и изучит структуру
2. ✅ Найдет селекторы для изображений, цены, характеристик
3. ✅ Filesystem прочитает SUPPLIERS_CONFIG из 05_supplier_parsing.gs.js
4. ✅ Создаст функцию parseNewshopImages() по аналогии с существующими
5. ✅ Memory Bank сохранит специфику парсинга newshop.ru

## 📊 Типичные задачи → MCP стратегия

| Задача | MCP серверы | Порядок действий |
|--------|-------------|------------------|
| **Починить парсинг** | Playwright + Filesystem + Memory Bank | 1. Playwright - анализ сайта<br>2. Filesystem - обновление кода<br>3. Memory Bank - сохранение решения |
| **Обновить API метод** | Context7 + Filesystem + Memory Bank | 1. Context7 - актуальная документация<br>2. Filesystem - рефакторинг кода<br>3. Memory Bank - запись изменений |
| **Добавить функционал** | Context7 + Playwright + Filesystem + Memory Bank | 1. Context7 - изучение best practices<br>2. Playwright - тестирование (если веб)<br>3. Filesystem - реализация<br>4. Memory Bank - архитектурные решения |
| **Отладка ошибки** | Filesystem + Context7 + Memory Bank | 1. Filesystem - чтение кода<br>2. Context7 - проверка актуальности<br>3. Memory Bank - known issues |

## 🚀 Продвинутые техники

### 1. Кэширование знаний в Memory Bank

**Создайте базу знаний:**
```
Сохрани в Memory Bank:
- veber-api-quirks.md - особенности API Veber.ru
- insales-rate-limits.md - лимиты InSales API и как их обходить
- openai-prompts-library.md - проверенные промпты для Assistants
- normalization-rules.md - правила нормализации спецификаций
```

**Преимущество:** В следующих сессиях я смогу использовать эти знания без повторного исследования.

### 2. Playwright для регрессионного тестирования

**Создайте тестовые сценарии:**
```
Используй Playwright для создания теста:
1. Открой InSales магазин
2. Найди товар с артикулом 26175
3. Проверь что все изображения имеют alt-теги
4. Проверь что SEO-filenames корректные
5. Сделай скриншот для отчета
```

**Сохрани этот сценарий** - можно будет запускать после каждого обновления.

### 3. Context7 для миграций

**При обновлении зависимостей:**
```
use context7 - что изменилось в OpenAI API за последние 3 месяца?
use context7 - deprecated методы Google Apps Script 2025
use context7 - breaking changes в InSales API v2
```

Это предотвратит внезапные поломки после обновлений.

## ⚡ Быстрые команды для повседневной работы

### Анализ кода
```
Проанализируй 05_supplier_parsing.gs.js и предложи улучшения
```
→ Filesystem читает + Context7 проверяет актуальность + Memory Bank сохраняет рекомендации

### Отладка парсинга
```
Veber.ru изменили структуру страницы, нужно обновить селекторы
```
→ Playwright анализирует сайт + Filesystem обновляет код + Memory Bank записывает изменения

### Проверка API
```
Проверь что я использую актуальные методы InSales API
```
→ Context7 получает документацию + Filesystem сканирует код + выдает отчет

### Сохранение контекста
```
Мы нашли решение для дубликатов товаров, сохрани это
```
→ Memory Bank создает detailed-solution.md с объяснением
